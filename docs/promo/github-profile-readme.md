**[Mini Krill](https://github.com/srvsngh99/mini-krill)** — A local-first AI agent that runs on your machine. Built in Go, powered by Ollama for fully private operation, with optional Codex and Claude Code support via official CLIs. Chat from Telegram, terminal CLI, TUI dashboard, or Discord — with unified memory across all interfaces. Runs seamlessly on Windows, Linux, and macOS. No API keys required to start.
